## 使用 1.15.2 本地验收

1. 用独立播放集仅启用本 Mod，开一份 1836 年大清测试档。查看「洋务自强」日志，确认显示 1861 年门槛且按钮灰显。
2. 要测试正式门槛，载入 **1861 年或以后**的大清测试存档，查看政治面板中的地主 Clout。如果暂时没有晚期存档，可将安装目录复制到临时播放集，改复制版 `.metadata/metadata.json` 的 ID 与名称，并只在复制版 `common/scripted_triggers/ssr_conditions.txt` 将 `year >= 1861` 改为 `year >= 1836`。在新测试档检查按钮到事件的完整路径，再移除临时版。该路径保持其余门槛及二十年期限，正式年份边界仍在正式版验收。
3. 地主 Clout 至少 20% 时点击「整顿旧制，推行新政」。确认只出现一份奏议，配图显示正常。可在奏议待处理时保存重载，再检查按钮仍无法另开一份奏议。
4. 先选「此事尚需从长计议」，检查国家未获得修正，且仍可再次提议。第二次选「祖宗之法，亦当因时而变。」。
5. 查看国家的「洋务新政」及政治面板。核对地主的政治力量 −50%、认同度 −5，知识分子及实业家各政治力量 +25%、认同度 +5，剩余时间约 20 年。查看 Clout 的原版重新计算结果与现行法律。
6. 保存退出并重载，确认修正和剩余时间仍在、日志结案且无法再次实施。用另一份测试档确认共和制或外国无法开启，以及中国君主制继承后的资格。原版革命对已有修正的继承需要单独记录。
7. 查看 Victoria 3 用户数据目录下的 `logs/error.log`，搜索 `ssr_` 和 `self_strengthening_reform`。如有异常，请保留游戏与 Mod 版本、事件或政治面板截图、完整相关报错段和测试存档。

如需核对安装版的原版 ID，可在游戏安装目录的 `game/common` 中查找 `CHI`、`law_monarchy`、`je_group_internal_affairs` 及三个 `ig_` 定义，在 `game/events/warlord_china_events.txt` 和 `game/common/journal_entries/00_reunify_china.txt` 核对中央政府引用。测试步骤使用正常 Launcher 和游戏交互。
