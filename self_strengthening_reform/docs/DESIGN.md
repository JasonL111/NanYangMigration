# 功能设计

## 资格与日志

国家必须存在、由玩家控制且实行 `law_monarchy`。中国资格满足任一原版关系即可，分别是国家定义 `cd:CHI`、`civil_war_origin_country` 直接指向定义为 `cd:CHI` 的国家，以及被原版 `chinese_central_government` 全局引用指向。国家名称、主流文化和人物均不参与判断。原版指针的版本证据见[原生脚本参考](NATIVE_SCRIPT_REFERENCE.md)。

日志从满足中国君主制玩家条件时开放。年份和地主 Clout 的门槛放在按钮，方便开局查看。日志使用 1.15 的 `outcome` 读取成功记录，成功后按钮立即不可见，日志在原生更新时结案。失去中国君主制资格时日志可转为非活动。当革命获胜时允许原生机制继承日志。

## 奏议与一次性状态

1. 点击时重查资格，并用 `ssr_petition_country` 记下本局当前的奏议国家，再打开该国的事件。
2. 奏议保持原生的三个月处理期。两个选项均直接在当前国家拥有该奏议时释放记录。94 天的原生变量期限可清理意外丢失的事件记录，覆盖通常的三个月事件期限。奏议国消失时其他合格国家可以提出新奏议。
3. 实施选项再次核对奏议国、玩家、君主制、中国继承关系、年份、实际 Clout 与整局记录。事件在当前 Country 应用 `ssr_reforms`，随后以 `has_modifier` 确认容器已挂载，再写入无期限的 `ssr_reform_enacted`。已有同名修正时脚本也会拒绝叠加。
4. 暂缓是事件的默认选项。它只结束奏议并释放临时记录。临时记录、永久记录与二十年修正的生命周期相互独立。

任何合法的再次提议仍走同一按钮。改革期满时由引擎移除修正。国家分裂、形成与革命后的原生修正继承留给游戏处理。本 Mod 的全局资格标记不随国家切换重建。

## 作用域与执行成本

按钮、奏议和修正均在发动国的 Country 上运行。只有地主 Clout 检查进入指定的 Interest Group。国家级静态修正按集团 ID 传递给三个利益集团。安装包带独立元数据、日志、按钮、事件、双语和事件纹理。脚本没有 On Action、每日轮询、跨国迭代和外部运行时。
