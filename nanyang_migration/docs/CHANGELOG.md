# 变更记录

## 1.1.0 RC3 · Victoria 3 1.15.2

- 根据 RC2 实机计数将故障限定在来源筛选。直接从本国州遍历符合原生文化 ID 的 POP。尚未接收本批同文化移民的州可直接使用 POP。
- 已接收州只用可核对来源与余额的原 POP。转移前确认接收标记，防止国内目的州把本批新移民再次转出。
- 加入同文化候选计数，并用 RC2 归档与 RC3 对照测试 POP 变量不可用的场景。真实引擎仍待复测。

## 1.1.0 RC2 · Victoria 3 1.15.2

- 根据玩家 RC1 弹窗确认故障发生在原生移动调用前。替换配对路径中的临时列表、动态子效果参数和停止布尔值比较，改用原生州与 POP 枚举。
- 弹窗报告已启动配额、有效州份和通过筛选的配对，可区分分配、筛选和请求量计算问题。
- 用截图的来源和目的州数量添加回归场景，并验证多候选下停机及新到 POP 的标记保护。引擎复测仍待完成。

## 1.1.0 RC1 · Victoria 3 1.15.2

- 采用 country-context 永久日志，移除旧版结局字段。更新按钮配置与元数据。
- 由 State Region 查找实际州。来源快照分文化保留，全量所有州合格 POP 仍可参与。
- 逐笔用来源与目的两端的同文化 POP 数差核验实际完成量。未核验的请求立即停止当前批次，保存全局待确认锁。
- 保留迁移矩阵、目标额增长、成功记录及五年冷却。新增独立小额实机探针和可重复打包流程。
