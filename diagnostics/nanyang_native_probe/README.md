# 下南洋原生 POP 诊断 · 1.15.2

1. 将本诊断目录解压到用户 `Victoria 3/mod`，在 Launcher 中创建只启用此诊断的独立播放集。诊断与正式 Mod 分开安装。
2. 新建 1836 年大清测试档。让日志出现，暂停，另存一份独立基准档。
3. 打开“下南洋原生迁移诊断”。每个基准档只执行一项。依次从基准档重载，测试常数 100、动态 100、比例 10%、整个 POP。每项会找一块由外国持有的马来亚实际州，并选取既有劳动力又有家属的闽文化 POP。前三项候选 POP 总人数 1,000–10,000，整个 POP 项为 1–1,000。
4. 截图即时弹窗。关闭弹窗，推进一游戏日，截图隔日弹窗。若筛选没有找到对象，报告该结果。隔日读数可能包含正常人口变化。
5. 一次性提交游戏完整版本和校验码、诊断版本、各项两张弹窗截图及同次运行的 `logs/error.log`。如果有该版本已经导出的原生脚本文档，可附带 effects、triggers、event_targets 和 event_scopes 文件。无需打开控制台。

逐项对比来源与目的的闽人口、劳动力、家属和对象数。若常数 100 导致总人口变化多于 100，核对劳动力是否正好变化 100。对比动态和常数可排查数值参数绑定。对比即时 POP 合计和全州统计有助于辨别缓存。隔日报告用于诊断可见时机。原 POP 读数为 −1 时，该引用已无法读取。对象数变化可提示合并，精确合并规则仍须根据 POP 类型及实际结果判断。

诊断包不参与正式存档，只调用一次小额原生移动，不更新正式 Mod 的计数或冷却。报告保留原有测量值，避免重载后错误归因。
