# 1.15.2 本地验收

1. 从启动器启用本 Mod，进入独立的1836年大清测试档。确认外交事务分组能看到「动员侨民」。以一个外国开新档，确认它没有发动权限。
2. 在西婆罗洲检查兰芳（`LAN`）。历史参考的兰芳以客家人为原有主流文化，并有较大的客家社区。用当前游戏的人口与文化面板核实其 Tier、是否已有汉主流文化及全国四种人口合计。若它已达40%，可以直接测试，无需等待迁移。
3. 点击「动员侨民」。对照目标国点击前后的主流文化与人口，核实新增汉文化、原有主流文化保留、人口构成不变。结果计数是全球已确认国家数。再次尝试，已处理国家不得重复计算。
4. 保存、退出、重载，复查文化集合。在单独备份中测试中国变更政体，以及目标国变更政体、革命、形成新国家或重建后的处理。本 Mod 不承诺这些原版变化会继承动态文化。
5. 检查用户数据 `logs/error.log` 的本次运行部分，搜索 `ocm_` 和 `overseas_chinese_mobilization`。保留游戏版本、存档和对应行。

## 不等待人口增长的精确边界测试

在启动器的 Mod 工具另建**临时测试 Mod**。它不属于正式包，只用于新建测试档。先用本游戏安装的 `game/common/history/pops/` 搜索 `region_state:LAN`，核对实际州、所有权、同国是否还有其他 POP 历史条目。把匹配的原版历史文件复制到临时 Mod 的相同相对路径，保留同文件中其他国家的内容。仅在临时副本的 `region_state:LAN` 块中替换两个 POP 群：

```text
region_state:LAN = {
    create_pop = { culture = hakka size = 4000 }
    create_pop = { culture = bornean size = 6000 }
}
```

上述是公开历史脚本已有的 `POPS → s:STATE_WEST_BORNEO → region_state:LAN → create_pop` 形式。修改前核实安装版仍使用这一布局且两种文化 ID 存在，正式脚本自身不创建任何 POP。不改动游戏安装目录或已有存档。启用本 Mod 与临时 Mod 后新建大清档，先验证暂停开局时该国确实只有这10,000人，再验证兰芳能否受理。重新建档分别试 3,999/6,001 与 4,001/5,999，确保前者不受理、后者受理。如果有其他国家已合格，按钮仍会亮起，应通过兰芳的主流文化变化确认个别结果。

若要检查霸权级筛选，复制安装版中包含 `LAN` 的 `common/country_definitions/` 文件到同一临时 Mod，只把其 `tier` 改为 `hegemony`。在4,000/6,000测试档核实实际 Tier 后，兰芳不应获汉主流文化。因为游戏开局和文件加载取决于本地版本与播放集，核对实际人口及 Tier 是这组试验的一部分。测试完移除临时 Mod。以上不需要控制台命令。
